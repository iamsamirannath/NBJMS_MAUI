# NBJMS Members MAUI App

This repository contains a .NET MAUI app concept for a small finance member experience. The initial screen highlights member balances, contribution reminders, and recent activity.

## Features
- Member snapshot with savings and loan balances
- Quick actions for contributions, withdrawals, and loan requests
- Recent activity list for transaction history

## Next Steps

- Add navigation for detailed statements and loan management
- Implement service integrations for payments
